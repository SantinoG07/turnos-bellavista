# Manual de usuario

## Cliente

1. Creá una cuenta desde **Crear cuenta**. La contraseña debe tener ocho caracteres, una letra y un número.
2. Entrá en **Reservar**, elegí servicio, barbero, fecha y un horario disponible.
3. Revisá el resumen y presioná **Confirmar turno**. La pantalla de confirmación es el comprobante.
4. En **Mis turnos** podés consultar próximos e historial. Hasta dos horas antes podés cancelar indicando un motivo o reprogramar.

La disponibilidad y el importe los confirma el servidor: un horario visto puede dejar de estar disponible si otra persona lo toma antes de confirmar.

## Administración

1. Iniciá sesión con una cuenta administradora y abrí **Admin**.
2. Elegí fecha y estado para filtrar la agenda; las métricas resumen el día.
3. Para un turno confirmado, usá **Atender**, **Ausencia** o **Cancelar**. La cancelación exige motivo.
4. Buscá clientes para ver ausencias y usar **Desbloquear** cuando corresponda.
5. En **Bloqueos de agenda**, seleccioná profesional, inicio, fin y motivo. Podés quitar un bloqueo desde la lista.

Las cuentas demo locales son `cliente@bellavista.test / Cliente1234` y `admin@bellavista.test / Admin1234`. No deben usarse como credenciales de producción.
